# Project Rules

## Stack
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- Vite

## Frontend
- Build production-quality UI.
- Do not use generic AI/SaaS aesthetics.
- Do not default to purple gradients.
- Do not use excessive rounded cards.
- Use deliberate typography and spacing.
- Prefer reusable components.
- Mobile responsive.

## Code
- Do not rewrite unrelated files.
- Inspect existing code before modifying it.
- Reuse existing components.
- Keep changes minimal.
- Run tests/build after significant changes.

## Design
- Follow the frontend-design skill.
- Establish visual direction before implementation.
- Prefer distinctive but coherent visual systems.
- Avoid unnecessary dependencies.
